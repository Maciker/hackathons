# Hackathon Projects

A portfolio index for my independent hackathon projects: focused experiments in agentic software development, TypeScript, and geospatial engineering. Each project will live in its own repository, with its code, decisions, evaluation, and demo kept together.

The concepts below have been selected for exploration. This index does not claim completed builds or submissions. I’ll add each project’s repository, demo, and submission links as they become available.

## Selected projects

### GeoEvidence Red Team

**Hackathon:** [Hack Apertus](https://hackapertus.devpost.com/)  
**Concept:** Test whether a geospatial assistant can support its answers with verifiable evidence and abstain when the evidence is missing or unreliable. The final product and track will follow the challenge requirements.  
**Stage:** Concept selected · project repository not created yet.

### GeoVisual QA Agent

**Hackathon:** [OpenCV AI Competition](https://opencv26.devpost.com/)  
**Concept:** Compare two georeferenced orthophotos over a small area and flag candidate surface changes for GIS review. A flagged result is a candidate to inspect, not a confirmed change.  
**Stage:** Concept selected · project repository not created yet.

### SpecTrace

**Hackathon:** [Nebius × NVIDIA Global AI Hackathon](https://nebiusglobalaihackathon.devpost.com/)  
**Concept:** Connect a small software specification to implementation criteria, code changes, and test evidence, with agent execution in the sandbox required by the selected challenge track.  
**Stage:** Concept selected · project repository not created yet.

## How I build

I prefer TypeScript across the stack where the project and competition rules allow it. Each project stays independent, follows its own competition requirements, and distinguishes working software from planned scope. Demos, licenses, evaluation results, and submissions receive human review.

My reusable development workflow lives in [agent-workflow-code-ts](https://github.com/Maciker/agent-workflow-code-ts).
